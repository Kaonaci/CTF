# CTF
Репозиторий для решения интересных задач с различных CTF-соревнований. Содержит скрипты эксплуатации, конфигурации инструментов и технические разборы.

## Структура репозитория
Задачи организованы по иерархии: `Название_CTF / Название_таска`.

Пример:
- `AlfaCTF2026/`
  - `MAXIMUM/` — скрипты Frida для перехвата FCM, дампы трафика, описание IDOR.
  - `Another_Task/` — решение и эксплойт.

## Инструментарий
- **Mobile:** Frida, JADX, ADB.
- **Web:** Burp Suite, Whireshark, Python, curl, Postman (requests, curl_cffi and etc).
- **Reverse:** Ghidra, GDB.
- **Linux:** Bash, ssh.
